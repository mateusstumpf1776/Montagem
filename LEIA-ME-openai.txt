MONTAGEM · EDITOR DE MANUAIS

Consulte README.md para as instruções completas.

Use Node.js 24. Na pasta do projeto, execute npm ci e npm start.
Abra http://localhost:3000.
Para ativar a IA, configure OPENAI_API_KEY no ambiente do servidor.

1. Importe o Excel e confira a lista de peças.
2. Importe a vista explodida e, se desejar, um STEP ou PDF de apoio.
3. Adicione as imagens do procedimento e selecione as peças e quantidades.
4. Gere as chamadas e os passos. Revise o manual e clique em Baixar PDF.

A chave da API fica no servidor. Use Salvar backup para transferir seus manuais.
